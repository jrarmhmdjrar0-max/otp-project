## تشغيل التحقق الحقيقي عبر البريد

1. ثبّت الحزم:
`npm install`

2. انسخ ملف الإعدادات:
`copy .env.example .env`

3. عدّل `.env` بقيم SMTP الحقيقية.

4. شغّل السيرفر:
`npm start`

5. افتح:
`http://localhost:3000`

## نشر على Render (يعمل حتى لو جهازك مطفي)

1. ارفع المشروع على GitHub (بدون `.env`).
2. في Render اختر `New +` ثم `Blueprint`.
3. اختر نفس الريبو؛ Render سيقرأ `render.yaml` تلقائياً.
4. أضف متغيرات البيئة:
`SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`.
5. بعد انتهاء النشر استخدم رابط Render العام.

## السلوك المطبق

- رمز تحقق OTP حقيقي عبر البريد.
- الصلاحية: 10 دقائق.
- عدد المحاولات: 3.
- إعادة إرسال الرمز: موجودة.

## ملاحظات

- عند `register`: يتم إنشاء الحساب فقط بعد نجاح التحقق.
- عند `login`: يتم الدخول فقط بعد نجاح التحقق.
- بيانات OTP والحسابات محفوظة في `app.db`.
